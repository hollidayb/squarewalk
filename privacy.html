Privacy Policy

Square Walk does not access the internet. No data is input or output through that medium. With no internet, no personal data can be shared and no ads can be displayed.

Square Walk saves game data in a file in your Android device. Square Walk uses the file to reconstruct and continue a game in progress when needed.

This file can have your GPS (Global Positioning System) location. Even though this data remains inside the Android device, some players may not want to save a file with GPS data.

Square Walk deletes this file occasionally, when it is safe to do so.

To verify the file is deleted, follow this procedure:

After you are done playing, go back to the first menu (with the names of all the games) and exit the app. Since no game was in progress when you left the app, the file can be deleted. Enter the app again. The file will be deleted, and Square Walk will want new GPS data.
